# KRX 변동성완화장치(VI) - 알고리즘 트레이딩 관점

## 📌 VI(Volatility Interruption)란?

주가가 **급격하게 변동**할 때 시장을 일시 중단시켜 **과도한 변동성을 완화**하는 제도입니다.

- **목적**: 시장 안정화, 패닉 매매 방지, 투자자 보호
- **영향**: 알고리즘 초단타 매매에 **치명적 영향**
- **중요성**: VI 발동 시 **즉시 포지션 조정 필요**

---

## 🔴 정적 VI (Static VI)

### 발동 조건
- **비교가격 대비 ±10% 이상** 가격 변동 시 발동
- **비교가격**: 직전 거래일 종가 또는 당일 시가 중 하나

### 대상 종목
- KOSPI/KOSDAQ 전 종목 (일부 제외)
- ETF, ETN 포함

### 진행 방식
1. **즉시 발동**: 10% 이상 변동 시 즉시 거래 중단
2. **2분 단일가**: 단일가 매매로 2분간 진행
3. **재개**: 2분 후 연속매매 재개

### 알고리즘 대응 전략
- ⚠️ **±9% 도달 시 경고**: 발동 직전 포지션 정리
- ❌ **VI 발동 시**: 신규 진입 금지
- ✅ **재개 후**: 변동성 확인 후 신중한 재진입

---

## 🟡 동적 VI (Dynamic VI)

### 발동 조건
- **1분간 ±3% 이상** 급격한 가격 변동 시 발동
- 정적 VI보다 **더 민감**하게 작동

### 대상 종목
- KOSPI200, KRX300 구성 종목
- 대형주 및 유동성 높은 종목

### 진행 방식
1. **즉시 발동**: 1분간 3% 이상 변동 시 즉시 중단
2. **2분 단일가**: 단일가 매매로 2분간 진행
3. **재개**: 2분 후 연속매매 재개

### 알고리즘 대응 전략
- 🚨 **초단타 고위험 구간**: 1분간 2.5% 변동 시 이미 위험
- ⏸️ **발동 시**: 모든 주문 취소, 관망 모드 전환
- 📊 **재개 후**: 호가창 안정화 확인 후 재진입

---

## ⚡ VI 발동 시 시장 특성

### 1. 유동성 급감
- 매수/매도 호가 공백 발생
- 스프레드 급격히 확대

### 2. 변동성 증폭
- VI 재개 후 추가 급등/급락 가능
- 패닉 매매 심화

### 3. 체결 지연
- 단일가 매매로 전환되어 즉시 체결 불가
- 의도하지 않은 가격에 체결 위험

## 🎯 알고리즘 VI 대응 전략

### 사전 예방 (Pre-VI)

```python
# 예시: VI 위험 감지 로직
def check_vi_risk(current_price, base_price, timeframe="1m"):
    """VI 발동 위험도 체크"""

    # 정적 VI 위험도 (±10% 기준)
    static_change = abs(current_price - base_price) / base_price
    if static_change > 0.09:  # 9% 이상 변동
        return "STATIC_VI_RISK"

    # 동적 VI 위험도 (1분간 ±3% 기준)
    dynamic_change = calculate_1min_change(current_price)
    if abs(dynamic_change) > 0.025:  # 2.5% 이상 변동
        return "DYNAMIC_VI_RISK"

    return "SAFE"
```

### 발동 중 대응 (During-VI)

| 단계 | 행동 | 우선순위 |
|------|------|----------|
| 1 | 모든 미체결 주문 즉시 취소 | 🔴 긴급 |
| 2 | 보유 포지션 평가 (손절 검토) | 🔴 긴급 |
| 3 | 단일가 매매 참여 여부 결정 | 🟡 중간 |
| 4 | 재개 후 시장 상황 모니터링 | 🟢 일반 |

### 재개 후 대응 (Post-VI)

1. **관망 시간 확보**: 재개 후 최소 30초~1분 관망
2. **호가창 안정화 확인**:
   - 매수/매도 호가 공백 여부
   - 스프레드 정상화 여부
   - 체결량 안정화 여부
3. **신중한 재진입**:
   - 포지션 크기 50% 축소
   - 손절 라인 더욱 타이트하게 설정

## 📊 VI 발동 빈도 및 패턴

### 발동 빈도가 높은 시간대
- **09:00 ~ 09:30**: 개장 직후 (갭 발생 시)
- **13:00 ~ 14:00**: 뉴스/공시 집중 시간
- **15:00 ~ 15:20**: 종가 형성 직전

### 발동 빈도가 높은 종목 특성
- 시가총액 작은 중소형주
- 뉴스/이슈에 민감한 테마주
- 거래량 급증 종목

## ⚠️ 알고리즘 개발 시 주의사항

### 1. VI 감지 시스템 필수
```python
# 실시간 VI 감지 모니터링
class VIMonitor:
    def __init__(self):
        self.vi_status = {}  # 종목별 VI 상태

    def update(self, stock_code, price_data):
        """실시간 VI 위험도 업데이트"""
        risk = self.calculate_vi_risk(stock_code, price_data)

        if risk == "VI_TRIGGERED":
            self.emergency_stop(stock_code)
        elif risk in ["STATIC_VI_RISK", "DYNAMIC_VI_RISK"]:
            self.reduce_position(stock_code)
```

### 2. 강제 중단 로직 구현
- VI 발동 시 **자동으로 모든 주문 취소**
- 신규 진입 **완전 차단**

### 3. 백테스팅에 VI 시뮬레이션 포함
- 과거 VI 발동 데이터 수집
- VI 발동 시나리오 테스트

### 4. 리스크 관리 강화
- VI 발동 가능성 높은 종목은 **포지션 크기 축소**
- 변동성 급증 시 **손절 라인 더욱 타이트하게**
